## Deployment notes

The PostgreSQL resolver is designed for environments where a hostname returns multiple IPv4/IPv6 addresses but only a subset is reachable. It probes IPv4 addresses and uses the reachable address while preserving the database hostname for TLS verification.

For a managed production network where all provider addresses are reachable, `DATABASE_URL` can remain the normal Neon pooled URL. `DB_HOST_OVERRIDE` is available for controlled infrastructure deployments.

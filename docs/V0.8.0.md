# Settle v0.8.0 — AI + Evidence Intelligence

## Scope

v0.8.0 adds an asynchronous AI and dispute-defense pipeline on top of the verified-document, PayPal, BullMQ, PostgreSQL, S3 and audit foundations.

## Flow

```text
verified document
  -> AI extraction worker
  -> structured facts + source excerpts
  -> evidence facts

PayPal dispute webhook
  -> dispute synchronization
  -> deterministic evidence collection
  -> evidence pack
  -> AI defense analysis
  -> READY_FOR_REVIEW
  -> owner/admin approval
  -> PayPal evidence submission
```

## AI providers

Supported providers are selected with `AI_PROVIDER`:

- `gemini`: Google Gemini REST API
- `openai`: OpenAI-compatible `/chat/completions` API

AI is disabled by default. Enable it only after configuring `AI_API_KEY` and the desired model.

## Safety model

AI output is never trusted directly. It is validated with Zod, stored in `ai_runs`, and converted into evidence facts with source provenance. PayPal submission remains a deterministic, authenticated operation that requires an owner/admin approval state.

## PDF extraction

The worker uses `pdftotext` for PDF text extraction. The Docker image installs `poppler-utils` in both build and runtime stages.

## New database tables

- `ai_runs`
- `evidence_facts`
- `evidence_packs`
- `evidence_pack_items`

Migration: `drizzle/0008_ai_evidence_intelligence.sql`.

## New endpoints

```text
GET  /v1/documents/:id/ai-extraction
GET  /v1/disputes/:disputeId/evidence-pack
POST /v1/disputes/:disputeId/evidence-pack/review
POST /v1/disputes/:disputeId/evidence-pack/submit
```

## Operational notes

AI work is asynchronous and runs in the `settle-ai` BullMQ queue. Failed document extraction can be recovered by the worker. AI provider secrets are read only from environment variables and are not written to logs or AI run records.

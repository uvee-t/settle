# Settle v0.10.1

Migration packaging fix for v0.10.0.

The application code is unchanged. This release restores the Drizzle migration
journal metadata for migrations 0007 through 0010 so `drizzle-kit migrate`
can recognize the existing migration history and apply `0010_delivery_acceptance.sql`
when it is pending.

Run:

```bash
npm run db:migrate
npm run build
```

# Settle v0.9.0 — Milestone Billing

## Added

- Database-backed `milestone_invoices` binding.
- A milestone can be associated with at most one invoice.
- Completing a milestone creates a draft invoice in the same PostgreSQL transaction.
- Explicit `POST /v1/milestones/:id/bill` billing endpoint.
- Idempotency support for explicit milestone billing.
- `GET /v1/milestones/:id/invoice` lookup endpoint.
- `invoice.created` audit and outbox events for milestone-generated invoices.
- Concurrent billing requests converge on one invoice through the unique database constraint.

## Billing behavior

1. Milestone must belong to the authenticated workspace.
2. Milestone must be `completed`.
3. Milestone must have an amount.
4. Settle creates a draft invoice using the contract currency and milestone amount.
5. The invoice receives one line item sourced from the milestone.
6. A unique `milestone_invoices.milestone_id` constraint prevents duplicate billing.
7. PayPal is not contacted during billing; PayPal remains the payment rail and is invoked by the existing invoice send flow.

## Existing API compatibility

The existing milestone PATCH response remains the milestone object. When the PATCH changes a milestone to `completed`, invoice creation happens transactionally as a side effect.
